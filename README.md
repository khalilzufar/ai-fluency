# AI Fluency Portfolio

Public portfolio for Khalil Zufar's AI Fluency work: evidence-based case storytelling, a bounded personal agent, an automation workflow, and documented website QA.

## Live site

After GitHub Pages is enabled:

<https://khalilzufar.github.io/ai-fluency-portfolio/>

## What's inside

- `index.html` - responsive public portfolio and interactive case explorer
- `demo.mp4` - caption-led 16-second walkthrough
- `blank/` - near-blank page milestone
- `ai_fluency/` - agent, MCP, workflow, QA, documentation, and submission notes

The portfolio is public-safe and contains no private warehouse data, tokens, or tracking identifiers. The ML evidence case links back to the main [FlyRank-ML repository](https://github.com/khalilzufar/FlyRank-ML).
